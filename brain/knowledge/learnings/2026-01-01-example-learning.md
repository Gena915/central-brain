# Example learning — save the WHY, not just the fix (delete or adapt)

**Section:** knowledge/learnings
**Date:** 2026-01-01
**Tags:** example, learning, decisions

## Context
This is a sample `learnings/` file showing the mold. A learning captures a
**problem → root cause → solution** or a **decision + why**, so the same mistake is never
made twice and the same debate is never re-litigated.

## Problem
(What went wrong, concretely.)

## Root cause
(Why it really happened — not the symptom.)

## Solution
(What fixed it, with the command/file/step that worked.)

## Decision + why
(If this was a decision rather than a bug: what was decided, and the reasoning that future
sessions must not re-argue.)

## Takeaway
One line the Brain should remember forever.
