# work/ — everything professional

> Your professional life: employer and/or clients. Each client (or your employer) is a
> **client mold**: same shape every time so navigation is predictable.

**Path:** work/
**Last updated:** seeded on install

## Sections
- [example-client/](./example-client/) — sample client mold (copy it for each real client, then delete).

## The client mold
Each client folder holds:
- `credentials.md` — pointers to where secrets live (never the secret itself).
- `info.md` — what the client is, contacts, scope.
- `agents/` — architecture + goal per AI agent you built for them.
- `docs/` — transcripts, requirements, pending items, diagrams, files.
