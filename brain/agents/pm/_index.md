# pm/ — your project manager agent

> The working files for the `/pm` skill. They're created/filled the first time you use it —
> this folder just gives it a home so nothing lands loose.

**Path:** agents/pm/
**Last updated:** seeded on install

## Content (created on first use)
- `definition.md` — the PM's identity and flows (optional; the skill has its own).
- `owner-as-pm.md` — your criteria + the exact format of your team message.
- `board.md` — current tasks and their state.
- `reminders.md` — recurring things to remember.

## Sections (created on first use)
- `team/` — one file per teammate (profiles used to assign tasks).
- `calls/` — dated transcripts/notes per meeting.

Run `/pm` to get started; it will ask for what it needs and fill these in.
